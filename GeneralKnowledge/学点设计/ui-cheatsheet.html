按钮Button组件

用于开始一个即时操作

适用场景

一个区域内通常只有一个主按钮，其余用次按钮或幽灵按钮承载优先级更低的操作。

关键细节

五态齐全：默认/hover/active/focus/disabled；点击态用 scale(.96) 而不仅是变色。

代码
.btn-primary{
  background: var(--accent);
  transition: transform .12s ease-out;
}
.btn-primary:active{ transform: scale(.96); }

图标按钮Icon Button组件

仅用图标表达的紧凑操作

适用场景

工具栏、表格行内操作等空间紧张、语义足够通用（增/删/改）的场景。

关键细节

点击区域不小于 36×36px，即使图标本身更小；仅一个"强调操作"用填充色，其余用描边或纯图标。

代码
.icon-btn{
  width:36px;height:36px;border-radius:9px;
  display:flex;align-items:center;justify-content:center;
}
.icon-btn.filled{ background:var(--accent); color:#fff; }
标签页Tabs组件

在同一区域内切换不同视图

适用场景

同一层级、少量（2-5个）视图之间切换，切换后内容整体替换而非叠加。

关键细节

选中态的下划线从上一个位置滑动过去，而非瞬间跳变，提升高级感。

代码
.tab-btn.active::after{
  content:''; position:absolute; left:0; right:0; bottom:0;
  height:2px; background:var(--accent);
}

.toggle.on{ background: var(--accent); }

暗示"这个东西可以点"

适用场景

最基础的可交互反馈，用于任意可点击的卡片、列表项。

关键细节

骨架屏Skeleton动画

数据未返回时的占位反馈

适用场景

接口请求耗时较长时，用和真实内容形状相近的占位块代替空白。

关键细节

45度渐变高光左右扫过，周期 1.2-1.6 秒，太快会显得焦躁。

代码
.skeleton{
  background-size: 400% 100%;
  animation: shimmer 1.4s ease-in-out infinite;
}
交错入场Stagger动画

依次出现，引导视线顺序

适用场景

一组内容（列表、卡片网格）在首屏或滚入视口时的入场动效。

关键细节

每项延迟 40-80ms，超过 120ms 会显得拖沓；位移幅度要小（8-16px）。

代码
/* 逐项设置 transition-delay: i * 60ms */
.item{ opacity:0; transform: translateY(8px); }
.item.in{ opacity:1; transform: translateY(0); }
涟漪点击Ripple动画

强化"点击已被接收"的反馈

适用场景

Material 风格的按钮点击反馈，强调即时性。

关键细节

涟漪中心取实际点击坐标；扩散 300-450ms；严肃/密集型产品需克制使用。

代码
r.style.left = (e.clientX - rect.left) + 'px';
r.style.top  = (e.clientY - rect.top)  + 'px';
淡入淡出Fade动画

内容切换最基础的过渡

适用场景

内容切换、弹层出现/消失时最基础、最通用的过渡方式。

关键细节

时长 150-250ms；配合 8px 内的轻微位移，比纯透明度变化看起来更自然、不生硬。

代码
.fade{ opacity:0; transform:translateY(6px); }
.fade.show{ opacity:1; transform:translateY(0); }
旋转加载Spinner动画

局部区域加载中的兜底方案

适用场景

局部区域数据加载中、且不方便用骨架屏占位时的通用方案。

关键细节

旋转周期 0.8-1s、用 linear 而非 ease，匀速旋转才不会有忽快忽慢的诡异感。

代码
@keyframes spin{ to{ transform:rotate(360deg); } }
.spinner{ animation: spin .8s linear infinite; }
摇晃Shake动画

表单校验失败时的强反馈

适用场景

表单校验失败时的反馈，比单纯把边框变红更抓眼球、更容易被注意到。

关键细节

水平位移控制在 ±6px 内，时长 300-400ms；幅度太大会显得滑稽而不是"提醒"。

代码
@keyframes shake{
  25%{ transform:translateX(-6px); }
  75%{ transform:translateX(6px); }
}

标注"进行中"的持续状态

适用场景

标注"进行中"的状态指示点，例如直播中、录音中、监听中。

关键细节

周期 1.5-2s，缩放和透明度同时缓慢变化；太快会显得紧张而不是"平稳运行"。

代码
@keyframes breathe{
  0%,100%{ transform:scale(1); opacity:1; }
  50%{ transform:scale(1.4); opacity:.5; }

十二栏网格12-Col Grid布局

网页设计的基础骨架

适用场景

把宽度切成 12 份，方便 2/3/4/6 等分组合（12 能被这些数整除）。

关键细节

移动端退化为 4 栏或单栏；gutter 要和间距阶梯对齐，常见 16-24px。

代码
.grid{
  grid-template-columns: repeat(12, 1fr);
}

后台管理类产品的常见骨架

适用场景

侧栏承载导航和层级，主内容区承载当前任务，多用于后台/工作台。

关键细节

侧栏宽度通常固定（200-280px）；折叠用宽度过渡+图标旋转组合。

代码
.layout{
  grid-template-columns: 240px 1fr;

用面积大小表达内容重要程度

适用场景

官网首屏、能力展示页，把不同重要程度的内容排成不规则网格。

关键细节

用 grid-template-areas 手动指定每块位置；尺寸档位不要超过 4 种。

.feature{ grid-column: span 2; grid-row: span 2; }

滚动时局部内容保持可见

表格表头、页面顶部操作栏等需要在滚动过程中始终可见的元素。

关键细节

position: sticky 搭配 top: 0；注意父级元素不能设置 overflow: hidden，否则会导致粘性失效。

同类目卡片的紧凑陈列方式

移动端展示同类目卡片（分类、推荐位），又不想占用过多垂直空间。

首尾露出"半张卡片"暗示可以继续滑动；配合 scroll-snap 让停靠位置对齐卡片边缘。

间距阶梯Spacing令牌

固定阶梯而非任意数值

适用场景

所有 padding / margin / gap 的取值依据，让界面在视觉上呼吸得一致。

关键细节

基础单位 4 或 8px；避免 13px、19px 这类不在阶梯上的孤儿数值。

代码
--space-2:8px; --space-4:16px;
--space-5:24px; --space-6:32px;
圆角阶梯Radius令牌

圆角要和元素尺寸成比例

适用场景

按钮/输入框用小圆角，卡片用中圆角，头像/胶囊用全圆角。

关键细节

同一产品只保留 3-4 档；避免直角和大圆角混用显得不统一。

代码
--radius-s:8px; --radius-m:14px; --radius-full:999px;
阴影阶梯Elevation令牌

阴影表达层级，而非装饰

适用场景

弹窗 > 下拉菜单 > 卡片，层级越高阴影越大、越虚、偏移越明显。

关键细节

紧阴影+环境阴影两层叠加效果更干净；深色背景改用描边表达层级。

代码
box-shadow: 0 1px 2px rgba(0,0,0,.06),
            0 4px 10px rgba(0,0,0,.12);
颜色阶梯Color Scale令牌

主色的完整深浅阶梯

适用场景

给主色配一整套深浅阶梯（50-900），用于 hover / active / 背景等不同强调层级。

关键细节

50-100 用作浅色背景，500-600 用作主操作色（按钮、链接），700+ 用作深色文字或深色模式下的主色。

摇摆Wiggle动画

图标周期性小幅摇摆吸引注意

适用场景

通知铃铛、消息图标在有新内容时的低打扰提醒，区别于因错误触发的"摇晃"。

关键细节

大部分时间静止，只在动画周期的一小段（如 5%-15%）里摆动 2-3 次，制造"偶尔提醒"而非持续烦扰的感觉。

代码
@keyframes wiggle{
  0%,92%,100%{ transform:rotate(0); }
  94%{ transform:rotate(-12deg); } 96%{ transform:rotate(10deg); } 98%{ transform:rotate(-6deg); }
}

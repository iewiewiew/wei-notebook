## 一、整体赛制流程
1. 练习赛：多节试车、暖胎、调校车辆
2. 排位赛（单走）：每人2-3圈，计分圈2圈，满分100分，取前32名晋级
3. 正赛（双车追走淘汰赛）：32→16→8→4→半决赛→决赛
    - 每组对决2：双方轮流领漂、跟漂
    - 单轮满分10分，排位榜首初始额外+1分，总分高者晋级
    - 同分：加赛一轮

## 二、四大评分维度（总分100）
| 评分项 | 占比 | 评分标准 |
| ---- | ---- | ---- |
| 速度 | 25分 | 入弯/弯中/出弯速度高且稳定 |
| 角度 | 25分 | 侧滑角度45°–70°最佳，姿态保持连贯 |
| 线路 | 30分 | 精准走指定路线、贴标线、必过得分点，无抄近道 |
| 风格 | 20分 | 动作流畅、拉烟均匀、姿态美观、无多余修正 |

## 三、双车追走 加减分规则
### 加分项
- 跟车距离≤1米，全程同步角度、速度、线路
- 领车失误后，跟车安全避让、姿态稳定

### 直接扣分/判负项
1. 车身回正、终止漂移、原地停滞
2. 车身打转（180°/360°）、失控甩尾
3. 压线、偏离指定线路、漏过得分点、抄近路
4. 两车发生碰撞，责任方直接失分/淘汰
5. 领车故意阻挡、跟车恶意切位超车

## 四、赛道旗语速查
- 绿旗：发车、赛道正常，正常行驶
- 黄旗：前方危险，减速、禁止超车
- 红旗：比赛立即中断，全员停车
- 方格旗：单圈/整场比赛结束

## 五、违规处罚梯度
1. 轻度失误：口头警告、单项扣分
2. 中度违规：大幅扣分、单轮判负
3. 严重违规（故意碰撞、危险驾驶、无视旗语）：直接取消本场成绩

## 六、车辆&安全硬性要求（必达标）
1. 标配：防滚架、专业赛车座椅、六点式安全带、车载灭火系统、紧急断油开关
2. 驱动：主流以后驱为主，部分赛事允许四驱
3. 轮胎：使用赛事指定漂移胎，严禁光头胎
4. 改装：严格遵守赛事技术规格，禁止违规提升动力

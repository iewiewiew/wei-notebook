## 央企 vs 国企

| 对比项   | 国企（国有企业）                   | 央企（中央企业）                      |
| ----- | -------------------------- | ----------------------------- |
| 定义    | 国家出资的所有企业统称，范围大            | 由国务院国资委 / 中央部委直接监管的国企，是国企里的子集 |
| 监管主体  | 地方政府（省 / 市 / 区国资委、地方平台）    | 国务院国资委、财政部等中央部委               |
| 归属例子  | 深圳地铁、深圳特区建发、深圳建工、各地城投、地方水务 | 中建、中铁、中铁建、中交、中水、国家电网、中石油、招商局  |
| 资金来源  | 地方财政、地方国资平台                | 中央层面国资                        |
| 业务特点  | 大多服务本地：市政、城市基建、本地公交、园区开发   | 全国布局，很多是国家级基建、能源、通信、军工等战略行业   |
| 一句话总结 | 央企一定是国企，但国企不一定是央企          | 国企里的 “中央直属国家队”                |



## 基建工程六大专业分类

|工程类别|核心包含内容|主管单位|常见承建央企|
|---|---|---|---|
|房建工程|住宅、写字楼、商场、厂房、学校医院、办公楼|住建局|中建各局、中铁建工、中交地产建设|
|市政工程|城市道路、管网、雨污水、路灯、绿化、城市桥梁、综合管廊|住建局 / 市政园林局|中建、中铁、中交、地方建工|
|公路工程|高速公路、国省道、县乡公路、公路桥梁、公路隧道|交通局|中交、中铁、中铁建|
|铁路工程|高铁、普速铁路、车站、铁路桥梁隧道、铁路路基|国铁集团 + 交通主管部门|中铁、中铁建|
|水利工程|水库、堤防、河道治理、灌区、泵站、水电站|水利局|中水、中铁、中交|
|轨道交通|地铁、市域快轨、轻轨、地下车站、盾构隧道|轨道交通集团 / 交通局|中铁、中铁建、中建|



## 施工和监理

| 主体        | 核心定位                       | 主要职责                                                                                                                            |
| --------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 施工单位（乙方）  | 工程实施建造方，对工程质量、安全、进度、成本直接负责 | 1. 按图纸、规范、施工方案组织现场施工<br>2. 原材料、构配件进场自检，做好施工试验、资料留存<br>3. 落实现场安全文明施工，管控施工质量<br>4. 按合同工期推进进度，上报进度、签证、变更<br>5. 对施工缺陷进行整改，完成竣工验收、保修 |
| 监理单位（第三方） | 受建设单位（甲方）委托，监督管控施工过程       | 1. 审核施工方案、进度计划、人员设备资质<br>2. 进场材料、工序、隐蔽工程验收，旁站、巡视、平行检验<br>3. 检查现场安全、质量，发现问题下发整改通知<br>4. 核对工程量、审核工程款支付申请<br>5. 参与工程变更、竣工验收，整理监理资料 |
总结：施工是干活的，监理是盯着干活的。

## 一、目标与判断标准

| 维度 | 学完后应该能做到 |
| --- | --- |
| 认人 | 拿到一个项目名，能说出业主、设计、总包、监理分别是谁，活是怎么分包下去的 |
| 认流程 | 从立项到交付，能画出时间轴并指出每个阶段的卡点（图审、施工许可、竣工验收备案） |
| 认钱 | 看得懂一份工程量清单的组成，知道进度款、变更、签证、结算各自在什么时候发生 |
| 认责 | 出问题时能判断该找谁，五方责任主体的责任边界在哪里 |
| 落地 | 能给自己家收房列一份验收清单 |

判断标准一句话：**看到一条基建新闻，能还原出它背后的组织关系和钱的流向。**


## 二、两条学习路线

| 路线 | 学什么 | 目标 | 顺序 |
| --- | --- | --- | --- |
| A 行业视角（当前主线） | 产业链、参建各方、工程流程、造价与合同、招投标、验收 | 看懂一个工程从立项到交付是怎么被组织和结算的 | 角色 → 流程 → 钱 → 合同 → 规范 |
| B 本体视角（后续） | 读图、构造与材料、空间与形式、建筑史 | 看懂一栋房子本身为什么长这样 | 读图 → 构造 → 形式 → 历史 |

两点心得：

- 行业视角的核心不是背名词，而是认清**责任链**和**资金链**，这两个链条能解释现场 90% 的扯皮。
- 本体视角前期枯燥（读图、构造），但性价比最高，能直接用到自己房子上。


## 三、A 线 6 周计划

| 周次 | 主题 | 学什么 | 本周产出 | 验收标准 |
| --- | --- | --- | --- | --- |
| 第 1 周 | 角色与责任链 | 五方责任主体、代建/造价/图审/检测等配角、总包-专业分包-劳务分包 | 画一张具体项目（如留仙洞、某地铁标段）的参建方关系图 | 能说清"出质量问题该找谁" |
| 第 2 周 | 流程与许可 | 立项、可研、初设、施工图审查、招投标、施工许可、竣工验收备案 | 画一张从立项到交付的时间轴，标出卡点 | 能说清"这个项目现在到哪一步了" |
| 第 3 周 | 钱怎么算 | 造价五构成、定额计价 vs 清单计价、综合单价、进度款/结算/质保金 | 拆一份真实工程量清单里的一个综合单价 | 能说清"这笔钱为什么这么算" |
| 第 4 周 | 合同与扯皮 | GF-2017-0201 的工期、价款、变更、索赔条款；EPC/PPP/投资人+EPC | 整理 10 个典型扯皮场景对应的合同条款 | 能说清"这个变更该不该给钱" |
| 第 5 周 | 验收与规范 | GB 50300 四级验收、隐蔽工程、实体检测、保修期限 | 给自己家列一份收房验收清单 | 能说清"这活干得合不合格" |
| 第 6 周 | 跟一个真项目 | 监理月报/周报、招标公告、中标公示、住建局公开文件 | 写一篇项目复盘（1000 字内） | 能独立看懂一个项目的公开信息 |

节奏建议：每周 3~4 小时，1 小时读 + 2 小时找真实材料 + 1 小时写产出。**产出比阅读重要**，没有产出的一周等于没学。

时间紧就砍成 3 周：第 1 周角色+流程，第 2 周钱+合同，第 3 周验收+跟项目。


## 四、配套速查

### 4.1 产业链：钱和活是怎么层层往下走的

```
政府 / 业主（建设单位）
   │ 立项、出资、发包
   ├── 设计院（勘察、设计）
   ├── 招标代理 / 造价咨询（算钱、组织招标）
   ├── 总承包单位（施工总包 / EPC 总包）
   │      ├── 专业分包（幕墙、机电、消防、钢结构、精装）
   │      │      └── 劳务分包（班组：钢筋、木工、瓦工、水电）
   │      └── 材料设备供应商（甲供 / 乙供）
   ├── 监理单位（第三方监督）
   └── 检测机构（材料、结构实体检测）
```

关键点：

- **每一层分包都在切一次利润**，所以越往下越容易在材料和人工上找钱，这是质量问题的结构性根源。
- **甲供材**（甲方直接采购）通常是为了控成本和质量，但会带来保管、损耗、责任划分的扯皮。
- 总包不一定自己干，很多是"管理型总包"，现场干活的是分包和班组。

### 4.2 工程全流程：一个项目的一生

| 阶段 | 主要产出 | 主导方 | 关键动作 |
| --- | --- | --- | --- |
| 前期 | 项目建议书、可行性研究报告 | 建设单位 | 定规模、算投资、拿批文 |
| 立项 | 立项批复 / 备案 | 发改部门 | 政府投资项目走审批，社会投资项目走备案 |
| 勘察设计 | 初设 + 概算、施工图 + 施工图审查 | 设计院 | 施工图审查合格才能用于施工 |
| 招投标 | 招标文件、投标文件、中标通知书 | 建设单位 / 招标代理 | 公开招标、邀请招标；评定标 |
| 开工准备 | 施工许可证、临水临电、场地移交 | 建设单位 / 总包 | 投资额 30 万以下或建筑面积 300㎡ 以下可不办施工许可 |
| 施工 | 检验批、隐蔽验收、进度款申报 | 总包 + 监理 | 按图施工、按规范验收 |
| 竣工 | 竣工验收报告、消防/规划/档案等专项验收 | 建设单位组织，五方参加 | 验收合格才能交付使用 |
| 结算 | 竣工结算、审计、决算 | 造价咨询 / 审计 | 变更签证在此集中爆发 |
| 保修 | 保修书、质保金 | 施工单位 | 缺陷责任期一般 1 年，最长 2 年 |

记一条主线：**立项看钱够不够，设计看图对不对，招标看价合不合理，施工看做得像不像，结算看账认不认**。

### 4.3 参建各方：谁签字，谁担责

五方责任主体（质量终身责任制）：

| 主体 | 干什么 | 典型产出/责任 |
| --- | --- | --- |
| 建设单位（甲方/业主） | 出钱、发包、组织验收 | 对工程质量负总责；不得任意压缩合理工期、不得明示暗示违反强制性标准 |
| 勘察单位 | 地质勘察、提供勘察报告 | 地基基础方案的依据；勘察成果必须真实准确 |
| 设计单位 | 方案、初设、施工图 | 按强制性标准设计；设计文件要能指导施工 |
| 施工单位 | 按图施工 | 对施工质量负责；不得偷工减料、不得擅自修改设计 |
| 监理单位 | 受甲方委托监督 | 对施工质量承担监理责任；该旁站不旁站、该停工不停工会被追责 |

> 五方项目负责人对工程质量承担**终身责任**，工程交付后出了结构安全问题，人退休了照样追。

其他常见角色：

| 角色 | 一句话 |
| --- | --- |
| 代建单位 | 甲方不懂工程，委托专业公司代管项目 |
| 造价咨询 | 编标底、编清单、审结算，决定"这钱该不该给" |
| 招标代理 | 组织招标流程，保证程序合法 |
| 检测机构 | 材料复检、结构实体检测（回弹、钻芯、桩基检测） |
| 图审机构 | 施工图强制性条文审查，审不过不能开工 |
| 审计 / 财政评审 | 政府投资项目最后一道"砍价"关卡 |

### 4.4 钱怎么走：造价构成与付款节奏

工程造价构成（概算/预算口径）：

| 组成 | 内容 |
| --- | --- |
| 设备及工器具购置费 | 电梯、配电柜、空调主机等设备 |
| 建筑安装工程费 | 人工费、材料费、施工机具使用费、企业管理费、利润、规费、税金 |
| 工程建设其他费 | 土地费、勘察设计费、监理费、招标代理费、报建规费 |
| 预备费 | 基本预备费（不可预见）+ 涨价预备费 |
| 建设期利息 | 贷款项目才计 |
| 流动资金 | 生产经营性项目才计 |

建安费的两种算法：

- **定额计价**：按地方定额 + 信息价算，适合政府投资、国有资金项目。
- **工程量清单计价**（GB 50500）：甲方给清单，乙方报综合单价，市场竞争定价，目前主流。

付款节奏（常见，具体看合同）：

| 节点 | 比例（常见） | 说明 |
| --- | --- | --- |
| 预付款 | 10%~30% | 有的项目没有，靠垫资 |
| 进度款 | 按月计量，付 70%~85% | 监理审核工程量，甲方按比例付 |
| 竣工结算 | 付至 97% 左右 | 结算审完才付，审计周期可能拖很久 |
| 质保金 | 留 3% | 缺陷责任期满退还，可用保函替代 |

行业现实：**垫资 + 拖欠**是施工企业的常态风险，尤其是分包和劳务层；这也解释了为什么"低价中标"往往换来"偷工减料"。

### 4.5 合同与模式：谁在承担风险

| 模式 | 结构 | 特点 |
| --- | --- | --- |
| 施工总承包 | 甲方分别发包设计、施工 | 最常见；设计和施工容易脱节，变更多 |
| EPC 工程总承包 | 一家单位包设计 + 采购 + 施工 | 交钥匙；责任单一，但对总包能力要求高 |
| 专业分包 | 总包把幕墙、机电、消防等切出去 | 常见；资质和界面划分是关键 |
| 劳务分包 | 只包人工，不包材料 | 班组制；实名制和工资专户是监管重点 |
| PPP | 政府和社会资本合作，投资+建设+运营 | 重运营；财政承受能力论证是门槛 |
| BOT / BT | 建设-运营-移交 / 建设-移交 | BT 已被规范清理，BOT 多见于水务、垃圾处理 |
| 投资人 + EPC | 施工方带资入场 | 实质是把融资压力转给乙方，风险高 |

必读文本：**《建设工程施工合同（示范文本）》GF-2017-0201**。看懂它，合同里的工期、价款、变更、索赔、违约就都能对上号。

四个必须分清的概念：

- **变更**：甲方要求改（改图、加量），走变更程序。
- **签证**：现场发生的额外事实（多挖了土、临时加固），双方现场确认。
- **索赔**：一方违约或客观情况导致损失，按合同主张。
- **结算**：把上面这些全部算成钱。

现场最贵的不是施工，是**没及时签字的变更和签证**。

### 4.6 资质与监管：谁能接什么活

| 资质类别 | 例子 | 作用 |
| --- | --- | --- |
| 施工总承包资质 | 建筑工程、市政公用工程、公路工程等，分等级 | 决定能接多大规模的项目 |
| 专业承包资质 | 地基基础、钢结构、消防设施、建筑装修装饰、幕墙 | 专业工程必须有对应资质 |
| 施工劳务资质 | 劳务作业 | 2021 年后改为专业作业资质备案制 |
| 设计资质 | 综合、行业、专业、专项 | 出图资格 |
| 监理资质 | 综合、专业 | 承担监理业务 |
| 造价咨询 | 甲级/乙级 | 编审造价成果文件 |

监管三条线：

- **住建部门**：施工许可、质量安全监督、竣工验收备案。
- **发改部门**：立项、概算、政府投资项目审批。
- **行业主管**：交通（公路）、水利（水利）、国铁（铁路）各管一摊。

### 4.7 验收与保修：最后一道关

验收层级（GB 50300 建筑工程施工质量验收统一标准）：

```
检验批 → 分项工程 → 分部（子分部）工程 → 单位工程
```

| 层级 | 谁组织 | 说明 |
| --- | --- | --- |
| 检验批 | 监理工程师 / 建设单位项目技术负责人 | 最小验收单元，按工序划分 |
| 分项工程 | 监理工程师 | 由一个或若干检验批组成 |
| 分部工程 | 总监理工程师 / 建设单位项目负责人 | 地基基础、主体结构、装饰装修、屋面、给排水、电气等 |
| 单位工程 | 建设单位项目负责人 | 竣工验收；五方参加，质监站监督 |

两个高频动作：

- **隐蔽工程验收**：钢筋绑扎、防水层、预埋管线等被下一道工序盖住前必须验收留影像，事后无法复核。
- **实体检测**：混凝土强度回弹/钻芯、钢筋保护层厚度、桩基静载，是"看得见的证据"。

法定最低保修期限：

| 部位 | 保修期 |
| --- | --- |
| 地基基础、主体结构 | 设计文件规定的合理使用年限 |
| 屋面防水、卫生间/房间/外墙面防渗漏 | 5 年 |
| 供热与供冷系统 | 2 个采暖期、供冷期 |
| 电气管线、给排水管道、设备安装、装修工程 | 2 年 |

几个易混概念：

| 概念 | 含义 |
| --- | --- |
| 竣工验收 | 工程完成、验收合格、可交付使用 |
| 竣工验收备案 | 验收后向住建部门备案，走完行政程序 |
| 交付使用 | 业主实际接收，起算保修期 |
| 缺陷责任期 | 一般 1 年（最长 2 年），用于扣留/释放质保金 |
| 保修期 | 法定最低期限，与缺陷责任期不是一回事 |

### 4.8 行业黑话速查

| 词 | 意思 |
| --- | --- |
| 甲方 / 业主 | 建设单位，出钱的人 |
| 总包 / 分包 | 总承包单位 / 承接部分工程的专业或劳务单位 |
| 三通一平 | 水通、电通、路通、场地平整，开工前置条件 |
| 正负零 | 地下到地上的分界标高，常作为进度里程碑 |
| 垫资 | 乙方先自己掏钱干活，后收钱 |
| 进度款 | 按月按工程量支付的工程款 |
| 变更 / 签证 | 改设计的钱 / 现场额外发生的钱 |
| 索赔 | 按合同主张损失 |
| 旁站 | 监理对关键工序全过程现场盯守 |
| 平行检验 | 监理独立做一遍检测，不完全依赖施工方数据 |
| 甲供材 | 甲方直接采购供应给施工方的材料 |
| 交工 / 竣工 | 施工方完成 / 整体验收完成 |
| 质保金 | 预留的 3% 质量保证金 |
| 甩项 | 某些内容暂不完成先交工，留下尾巴 |

## 七、B 线开篇：一栋房子的结构从 0 到 1（通俗版）

先分清两件事：**建筑管布局样貌，结构管稳不稳、会不会倒**。

结构的核心任务：把房子所有的重量和外力，稳稳地传到地基，再交给大地承担。

荷载分两类：

| 类型 | 包含什么 |
| --- | --- |
| 恒载（一直存在） | 楼板、墙体、梁柱、屋面、地面装修层的自重 |
| 活载（会变化） | 人、家具、积雪；地震和大风属于突发外力 |

下面以最常见的城市高层住宅（钢筋混凝土框架-剪力墙结构）为主线讲。


### 7.1 前期方案：还没画图，先定骨架

1. 建筑设计师先出户型方案：房间怎么分、层高多少、电梯楼梯放哪、窗户开多大。
2. 结构工程师同步进场，重点看三件事：
   - 地质勘察报告：地下是什么土、承载力够不够、有没有软土和地下水，直接决定基础形式
   - 当地抗震和大风标准：确定结构形式，电梯井、楼梯间一般做成剪力墙核心筒，天然抗地震抗风
   - 初步规划：受力墙体和柱子放哪，楼板、梁大概多厚
3. 常识：户型不能随心所欲。超大阳台、长悬挑、大面积开洞，都会大幅抬高造价，甚至结构上做不了。


### 7.2 结构施工图（结施图）：给施工队看的受力说明书

一套图纸包含：结构总说明、基础图、柱子图、剪力墙图、梁和楼板配筋图、楼梯图、节点详图。

**基础（房子的脚，埋在地下）**

| 形式 | 适用场景 |
| --- | --- |
| 独立基础 | 低层、土质好，每根柱子下面单独一块 |
| 条形基础 | 砖混自建房常用，沿墙底连续做一条 |
| 筏板基础（满堂大板） | 高层住宅多用，一整块厚混凝土板，整栋房子坐上去分散重量 |
| 桩基础 | 土质松软、承载力差，把桩扎进深层好土，桩上再做承台或筏板 |

基础最重要的作用：控制沉降，防止一边沉得多、一边沉得少导致开裂。

**竖向骨架（承重的主力）**

- **剪力墙**：钢筋混凝土实心墙，既能承重，又抵抗地震和大风。高层住宅的电梯井、楼梯间大多是剪力墙，**绝对不能私自拆改**。
- **框架柱**：混凝土方柱，和梁搭成框架，承担竖向重量；纯框架高层较少，抗震能力偏弱。
- **填充墙**：后期砌的加气块隔墙，只分隔房间、不承重，和剪力墙完全两回事。

**水平骨架（楼板 + 梁）**

- 楼板：现在新房基本都是现浇混凝土板，人和家具的重量先给楼板，再传给梁或剪力墙。
- 梁：架在柱子和剪力墙上，把楼板荷载集中往下传。主梁搭在柱子上，次梁搭在主梁上、用来分割楼板。
- 大梁会占用高度，这就是家里吊顶位置常有梁的原因；想做无大梁户型，成本更高。

**为什么钢筋和混凝土要搭着用**

混凝土抗压很强，一拉就容易裂；钢筋擅长抗拉。所以混凝土扛压力，钢筋放在容易被拉开的位置扛拉力。

比如楼板中间的梁受弯下沉，梁底部被拉开，底部要放粗钢筋；支座位置上方被拉开，上部也要配筋。图纸上的配筋标注，就是规定钢筋放哪、多粗、间距多少。


### 7.3 主体施工：从下往上搭骨架

1. 开挖基坑，深基坑还要做护坡和降水，防止坑壁塌掉。
2. 桩基础先打桩，之后检测桩的承载力和完整性。
3. 绑扎基础钢筋 → 支模板 → 浇筑混凝土 → 养护硬化。
4. 地下室施工：墙柱钢筋 → 封模板 → 浇筑 → 养护，再做地下室梁板。
5. 地上楼层循环，一层一层重复：
   剪力墙/柱子绑钢筋 → 封模板 → 搭梁板模板 → 梁板钢筋绑扎 → 监理隐蔽验收 → 浇筑混凝土 → 养护到足够强度 → 施工上一层。
6. 屋面结构：屋面板、屋面梁、女儿墙结构。
7. 实体检测：回弹测混凝土强度、扫描钢筋保护层厚度，核对是否与图纸一致。

做到这里就是常说的**主体封顶**：受力骨架完成，房子已能稳稳扛住自重、大风和地震。

注意：**封顶 ≠ 交房**。骨架只是外壳，后面还有围护、机电、装修一大堆工序。


### 7.4 二次结构与后续工序

主体完成后做二次结构：用加气块砌隔墙分房间（不承重），同时做构造柱和门窗过梁。

构造柱、过梁不承担主要荷载，属于抗震构造措施，地震时防止小块墙体直接垮塌。

二次结构做完，才轮到防水、外墙、门窗、管线、抹灰和装修。


### 7.5 结构验收

建设、勘察、设计、施工、监理五方联合验收，结构分部验收合格，才能进入下一道工序。


### 7.6 几个普通人容易搞混的点

| 误区 | 正确理解 |
| --- | --- |
| 砖混就是砖 + 混凝土随便搭 | 砖墙直接承重，圈梁和构造柱主要是箍住墙体、提升抗震，老房子和农村自建房常见 |
| 封顶就是完工 | 封顶只是结构骨架完成，离交房还远 |
| 隔墙和剪力墙一样 | 隔墙只分隔房间、可以拆；剪力墙是受力构件，不能拆 |
| 抗震就是地震不会坏 | 标准是小震不坏、中震可修、大震不倒，靠结构体系和钢筋构造实现 |

简化传力路径：

```
人 / 家具 → 楼板 → 梁 → 剪力墙 / 柱子 → 基础 → 地下土层
```

户型不能随便改的原因：

- 剪力墙不能随便开大洞，洞口周边要额外加固钢筋
- 阳台悬挑不能无限加长，挑得越远，梁和配筋要大幅加强，造价飙升
- 大梁占用层高，想要看不到大梁，要用特殊楼板方案，成本更高

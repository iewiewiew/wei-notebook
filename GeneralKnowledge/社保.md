## 社保介绍

社保 = 五险（养老 / 医疗 / 失业 / 工伤 / 生育），国家强制
- 养老保险：退休后领养老金，“养你老”
- 医疗保险：看病住院报销、买药刷卡
- 失业保险：被裁员可领失业金
- 工伤保险：上班受伤 / 职业病，赔钱 + 治病
- 生育保险：生娃报销 + 发产假工资（生育津贴）

住房公积金 = 强制住房储金，买房租房用，单位和个人对半交
- 用途：买房贷款（利率低）、租房、装修、建房、销户提取
- 缴纳：单位交一份、你交一份，钱都进你个人账户

五险一金总览（深圳大致比例）

| 项目   | 谁交钱      | 大致比例             | 作用            |
| ------ | ----------- | -------------------- | --------------- |
| 养老   | 单位 + 个人 | 单位 14%，个人 8%    | 退休金          |
| 医疗   | 单位 + 个人 | 单位 6.2%，个人 2%   | 看病报销        |
| 失业   | 单位 + 个人 | 单位 0.6%，个人 0.2% | 失业金          |
| 工伤   | 仅单位      | 0.14%–1.14%          | 工伤赔偿        |
| 生育   | 仅单位      | 0.45%                | 生娃报销 + 津贴 |
| 公积金 | 单位 + 个人 | 各 5%–12%            | 买房租房        |



## 社保是如何运作的

### 1. 缴费：按 “缴费基数” 算钱

- 缴费基数：你的月工资（有上下限，深圳 2025 大概 2360–36549）
- 每个月：
  公司按基数 × 单位比例
  你按基数 × 个人比例（从工资里扣）

### 2. 钱去哪了：统筹账户 + 个人账户

- 统筹账户（大锅饭） ：单位大部分钱进这里
  - 用来给现在退休的人发养老金、报销医药费、发工伤 / 生育待遇中国人大网
  - 个人账户（你自己的）
  - 养老：个人 8% 全部进你账户，属于你，可继承中国人大网
  - 医疗：个人 2% + 单位小部分，进你医保卡，可刷卡买药、看门诊
  - 公积金：单位 + 个人全进你账户，完全是你的钱

### 3. 待遇怎么发（以养老、医疗为例）

#### 养老保险（退休领钱）

- 条件：累计缴满 15 年 + 到退休年龄（男 60 / 女 50–55）中国人大网
- 养老金 = 统筹养老金（大锅饭给）+ 个人账户养老金（你自己账户）中国人大网

#### 医疗保险（看病报销）

- 住院：统筹基金按比例报销（深圳一档约 70%–90%）
- 个人账户：刷卡付门诊、买药
- 退休：缴满年限（男 25 年 / 女 20 年），终身医保

#### 失业 / 工伤 / 生育

- 失业：非自愿离职，交满 1 年可领，最长 24 个月
- 工伤：上班受伤，全额报销 + 伤残补助，个人不掏钱
- 生育：生娃报销 + 产假工资（生育津贴）

### 4. 运作本质：代际互助 + 强制储蓄 + 风险分担

- 年轻人交钱 → 给现在老人发钱；等你老了，下一代养你
- 医疗 / 工伤 / 生育：大家凑钱，谁出事谁用，分散风险

断缴影响
- 养老：累计 15 年即可，中间断了可以补、可以续
- 医疗：断缴次月不能报销，个人账户余额还能用

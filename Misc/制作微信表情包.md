## 1. 平台入口

[微信表情开放平台](https://sticker.weixin.qq.com/)

注册 → 实名认证 → 创建表情专辑 → 上传素材 → 提交审核

## 2. 素材清单

一套表情专辑，**主图数量只能是 16 或 24 张**（全部静态或全部动态，不能混用）。

| 素材 | 数量 | 格式 | 尺寸 | 大小 |
|------|------|------|------|------|
| 表情主图 | 16 / 24 | GIF | 240×240 | ≤ 500KB |
| 表情缩略图 | 与主图一致 | PNG | 120×120 | ≤ 200KB |
| 表情封面图 | 1 | PNG | 240×240 | ≤ 500KB |
| 详情页横幅 | 1 | PNG / JPEG | 750×400 | ≤ 500KB |
| 聊天面板图标 | 1 | PNG | 50×50 | ≤ 100KB |

> 动态主图需设置永久循环播放；缩略图取主图关键帧，**不能有白色描边**。

## 3. 命名规则

主图与缩略图按数字编号一一对应：

```
01.gif  ↔  01.png
02.gif  ↔  02.png
...
```

## 4. 制作要点

- **风格统一**：同一套表情画风、配色保持一致
- **差异明显**：每张表情动作 / 情绪 / 文案不同，适合聊天场景
- **主图描边**：形象建议加 2px 白色描边，避免边缘锯齿；不要贴边
- **文字清晰**：文案简短（2～4 字为佳），识别性高
- **缩略图 / 封面 / 图标**：透明底，无白色描边
- **详情页横幅**：不透明底，不用白色或接近白色的背景，不加文字

## 5. 快速制作流程

```
确定主题与角色
    ↓
列出 16 / 24 个聊天场景（加油、OK、晚安……）
    ↓
绘制 / 生成主图（240×240）
    ↓
静态图转 GIF（动态则逐帧导出）
    ↓
生成缩略图（120×120）+ 封面 + 横幅 + 面板图标
    ↓
按规范命名、检查文件大小
    ↓
上传平台，填写含义词，提交审核
```

### AI 辅助生成（可选）

用参考照片 + 提示词生成动漫风表情，再统一处理尺寸：

```bash
# 批量缩放到 240×240，透明底居中
python3 -c "
from PIL import Image; import glob, os
for f in glob.glob('*.png'):
    img = Image.open(f).convert('RGBA')
    s = min(240/img.width, 240/img.height)
    r = img.resize((int(img.width*s), int(img.height*s)), Image.LANCZOS)
    c = Image.new('RGBA', (240,240), (0,0,0,0))
    c.paste(r, ((240-r.width)//2, (240-r.height)//2), r)
    c.save(f, 'PNG', optimize=True)
"
```

静态 PNG 可用 [ezgif.com](https://ezgif.com/png-to-gif) 等工具转为 GIF 后上传。

## 6. 审核注意

- 必须原创或拥有版权
- 不含政治、暴力、色情等违规内容
- 详细规则见平台内 [《微信表情制作规范》](https://sticker.weixin.qq.com/) 与《作品审核标准》

## 7. 知识碎片

商店上架专辑：每月仅 1 次修改机会，提交后无论驳回 / 通过，当月无法二次编辑，必须等次月 1 日重置额度。可增 / 删 / 换图、改文案，需二次审核，总量 8–24 张封顶。

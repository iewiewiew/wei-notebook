# 新人测试：Mac 桌面端应用完整测试指南
## 一、测试前准备（新人必做基础环境）
### 1. 必备硬件&系统环境
1. Mac 机型覆盖（最小测试集）
    - Intel 芯片 Mac（MacBook Pro/Air、iMac）
    - Apple Silicon（M1/M2/M3/M4）Mac（主流新机型，架构不同极易兼容问题）
2. 系统版本梯度（根据产品最低兼容要求选3档）
    - 最低兼容系统（兜底兼容性，如 macOS 12 Monterey）
    - 主流稳定版（macOS 14 Sonoma，用户量最高）
    - 最新正式版（macOS 15 Sequoia，适配新系统特性）
> 提示：不要只用自己一台Mac测，架构、系统版本是Mac端最容易出BUG的点
3. 辅助工具安装（免费刚需）

|工具|用途|
|----|----|
|Activity Monitor（自带）|查看CPU、内存、磁盘、网络占用，崩溃卡死定位|
|Console（控制台，自带）|查看App日志、崩溃日志、报错堆栈|
|Terminal（终端）|权限调试、文件路径查看、进程杀死、命令行启动看报错|
|Xcode|获取完整崩溃报告、符号化崩溃日志、调试沙盒权限|
|OnyX|缓存清理、权限修复（测试异常场景用）|

### 2. 安装包类型区分（Mac安装包格式）
Mac 应用安装包不同，安装卸载测试逻辑完全不同：
1. .dmg 镜像包：最常见，挂载拖拽到Applications文件夹安装
2. .pkg 安装包：向导式安装，有权限请求、自定义安装路径
3. App Store 上架包：受沙盒严格限制，权限、文件读写受限最多
4. 独立.app 绿色包：直接运行，无需安装

## 二、核心测试模块（新人按顺序全覆盖）
### 模块1：安装/卸载/升级测试（入门最先测）
#### 安装测试点
1. 正常安装：dmg挂载、拖拽到应用程序、pkg向导下一步完成，无报错弹窗
2. 权限安装：安装时请求磁盘、辅助功能、屏幕录制、摄像头权限，拒绝/允许两种分支
3. 异常安装：
    - 磁盘空间不足（低于安装所需大小）安装是否友好提示
    - 安装中途强制断网、关机、退出安装程序，是否残留垃圾文件
    - 重复覆盖安装新版本，旧配置是否保留/清空（看产品需求）
4. 路径测试：自定义安装路径（pkg支持）、移动.app到非Applications文件夹能否正常启动

#### 卸载测试点
1. 常规卸载：废纸篓拖入App、启动台长按删除、pkg自带卸载器卸载
2. 残留文件校验（重点）：卸载后检查残留目录，必须清理干净
    ```
    ~/Library/Application Support/应用名
    ~/Library/Preferences/应用配置.plist
    ~/Library/Caches/应用缓存文件夹
    /Library/Application Support（全局公共目录）
    ```
3. 卸载中异常：卸载中途强制结束进程，再次卸载是否无异常

#### 版本升级测试
- 低版本在线升级、手动替换高版本.app，配置、登录态、本地文件不丢失
- 跨大版本升级，旧数据兼容（比如v1.0本地文件v2.0能否读取）
- 升级失败回滚：升级断网/崩溃，能否退回旧版正常运行

### 模块2：启动&退出稳定性（Mac高频崩溃场景）
#### 启动场景
1. 冷启动：开机首次打开，加载速度、无闪退、无卡死
2. 热启动：关闭后反复快速启停，连续10次以上稳定性
3. 后台唤醒启动：Mac休眠唤醒后，后台挂起App恢复前台是否正常
4. 权限缺失启动：拒绝必备权限后启动，是否给出引导授权弹窗，而非直接崩溃
5. 开机自启：设置登录时启动，重启Mac后自动唤起正常

#### 退出场景
1. 正常退出：菜单栏退出、Command+Q、右键dock退出，进程完全关闭（Activity Monitor无残留）
2. 强制退出：卡死时通过强制退出关闭，下次启动无配置损坏
3. 后台驻留：最小化到dock后台，长时间挂着（1h+）内存泄漏、后台掉线检测

### 模块3：窗口与界面适配（Mac UI专属测试）
1. 分辨率&缩放适配
    - 视网膜屏（Retina）、非Retina屏图标、文字模糊问题
    - 显示器缩放：系统100%/125%/150%缩放，界面控件不挤压、不溢出
    - 外接显示器：单屏切双屏、投屏，窗口跟随移动、最大化还原正常
2. Mac专属窗口操作
    - 左上角红黄绿按钮：关闭、最小化、全屏（Mac全屏独立桌面）
    - 分屏模式：系统台前调度、左右分屏，App布局适配
    - 拖拽窗口边角缩放，自适应布局无错乱
3. 暗黑/浅色模式
   跟随系统外观切换、手动切换App明暗主题，配色、文字对比度正常，无看不见文字
4. 菜单栏与Dock
    - 顶部系统菜单栏：App自定义菜单（文件、编辑、偏好设置）功能可用
    - Dock图标：角标、右键快捷菜单、右键退出、偏好设置入口正常

### 模块4：权限测试（Mac沙盒核心坑点，极易漏测）
Mac 隐私权限管控极严，App无权限会直接功能失效甚至闪退，重点测这些权限：
1. 文件访问：下载文件夹、桌面、文稿、外接U盘读写
2. 辅助功能：快捷键、全局截图、后台控制必备权限
3. 屏幕录制：录屏、截图、窗口捕捉功能
4. 麦克风/摄像头：音视频通话、录制功能
5. 网络权限：Wi-Fi/有线网络、代理、VPN环境联网
   分支测试：先拒绝权限→功能提示授权→重新授权→功能恢复；撤销权限后功能降级提示，不崩溃

### 模块5：文件读写与本地数据测试
1. 新建/保存文件：保存到桌面、文稿、外接硬盘、iCloud云盘
2. 大文件处理：超大视频、压缩包、文档，内存不暴涨、不卡死
3. 文件关联：后缀文件双击默认唤起本App，右键打开方式切换正常
4. 离线数据：断网后本地缓存、草稿、历史记录保留，联网后同步正常
5. iCloud同步：开启iCloud云同步，多Mac设备数据同步一致性

### 模块6：快捷键、输入法、本地化适配
1. 系统全局快捷键：Command+C/V/X/Z、Command+S、Command+逗号（偏好设置）
2. App自定义快捷键：自定义全局热键，冲突系统快捷键时友好提示
3. 输入法：简体中文、繁体、英文、第三方输入法（搜狗、百度输入法）输入无乱码
4. 多语言本地化：英文、中文切换，按钮、弹窗、提示文案翻译完整，无占位符

### 模块7：性能测试（新人简易版，无需专业工具）
1. 内存泄漏：多次打开关闭功能，Activity Monitor观察内存只涨不降则为泄漏
2. CPU占用：闲置状态CPU极低，高负载（导出、渲染）峰值合理，无持续满载发烫
3. 磁盘IO：批量导出文件，无卡死、写入损坏
4. 长时间稳定性：后台挂机4小时，无自动退出、掉线、内存溢出

### 模块8：网络异常场景测试
1. 正常Wi‑Fi、有线、手机热点切换网络
2. 弱网：限速网络、高延迟，加载转圈友好，无卡死
3. 断网：断网操作提交数据，缓存本地，联网自动同步
4. 代理/VPN：开启系统代理，登录、接口请求正常

### 模块9：崩溃、日志排查（新人定位BUG方法）
#### 快速找崩溃日志路径
1. 控制台Console → 崩溃报告 → 用户崩溃报告
2. 访达路径：`~/Library/Logs/DiagnosticReports/` 后缀.crash文件
#### 测试要求：
- 复现崩溃步骤清晰，附上崩溃日志截图、系统版本、芯片类型
- 卡死无响应：区分是App逻辑卡死还是系统卡顿，通过终端kill进程验证

## 三、Apple Silicon vs Intel 架构专项测试（重中之重）
1. 通用二进制包（Universal）：两种芯片都原生运行，无Rosetta转译兼容问题
2. Rosetta 2转译：Intel包在M系列Mac运行，性能、弹窗、权限是否异常
3. 硬件调用：M系列GPU加速、神经网络引擎，渲染、导出功能加速生效
4. 安装路径权限：Apple Silicon沙盒权限更严格，部分旧Intel插件无法加载

## 四、Mac专属系统特性兼容测试
1. 台前调度、专注模式：专注模式下后台通知是否合规提醒
2. 隔空投送：App内文件支持隔空投送分享
3. 快捷指令（Shortcuts）：适配系统快捷指令自动化触发
4. 锁屏/睡眠：锁屏后台任务（下载、转码）是否按产品需求继续/暂停
5. 钥匙串：账号密码保存到Mac钥匙串，重启后自动填充

## 五、新人提BUG规范（Mac端专属描述模板）
固定要素缺一不可：
1. 设备：MacBook Pro M2 / Intel i7 iMac
2. 系统版本：macOS 14.6 Sonoma
3. App版本：V2.3.1
4. 复现步骤：一步步最简操作
5. 预期结果、实际结果
6. 附件：截图、录屏、崩溃日志、Console日志片段

## 六、新人避坑高频易错点
1. 只测自己常用系统，不覆盖最低兼容系统，上线老Mac大面积闪退
2. 忽略Apple Silicon Rosetta转译问题，Intel老程序在M芯片异常
3. 卸载不校验残留文件，多次安装配置错乱
4. 权限拒绝后未做降级提示，直接崩溃
5. 全屏、分屏、外接显示器UI适配遗漏
6. 暗黑模式配色失效，浅色文字在深色背景看不见
